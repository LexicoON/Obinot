Get started with Obinot

Install the app, get a free API key and record your first note. No technical knowledge needed.

1 · Install 2 · What is an API key? 3a · Groq key 3b · Gemini key 4 · First note Troubleshooting

1. Install the app

  1. 1

    Download the APK

    Tap Download APK at the top of this page. It comes straight from the project's GitHub releases.

  2. 2

    Allow the install

    Open the downloaded file. If Android asks, allow installing apps from your browser (or file manager) — you only do this once.

  3. 3

    Open Obinot

    Follow the short welcome. It will ask for microphone access (to record) and, optionally, notification access (to keep recording in the background).

Obinot is not on the Play Store. Download it only from the official GitHub page linked on this site.

2. What is an API key, and why do I need one?

Obinot doesn't run its own servers. To turn speech into text and structure it, it asks an AI service — Groq or Google Gemini — directly from your phone. An API key is a long password that tells that service the request is yours. Both offer free tiers that are plenty for personal use.

Groq

Very fast. Great for everyday notes and short or medium recordings. Has a 25 MB file limit (Obinot can compress audio to fit).

Gemini

Handles very long recordings, like a full lecture or meeting. Slightly slower (not recommended for free API).

Dynamic

Add both keys and Obinot picks the best provider for each task, saving your free quota.

Treat your key like a password. Don't post it in screenshots, chats or public forums. Obinot stores it on your device only.

Recommended to start

3a. Get a free Groq key

  1. 1

    Open the Groq console

    Go to console.groq.com/keys and sign in (or create a free account).

  2. 2

    Create the key

    Tap Create API Key, give it any name (for example “Obinot”) and confirm.

  3. 3

    Copy it right away

    The key is shown only once. Copy it to your clipboard before closing the window.

  4. 4

    Paste it in Obinot

    During the welcome, choose Groq and paste the key. You can also do it later in Settings.

Best for long recordings

3b. Get a free Gemini key

  1. 1

    Open Google AI Studio

    Go to aistudio.google.com/app/apikey and sign in with your Google account.

  2. 2

    Create the key

    Tap Create API key. If it asks for a project, pick the default one or create a new one.

  3. 3

    Copy it

    Copy the key that appears. You can come back to this page to see it again.

  4. 4

    Paste it in Obinot

    Choose Gemini in the welcome (or in Settings) and paste it.

Want both? Add the second key too and switch to Dynamic mode. Providers update their sign-up screens from time to time, so button names may look slightly different.

4. Record your first note

  1. 1

    Press Record

    On the first tab, tap Record and talk. Pause or stop with the buttons. Already have audio? Use the music-note button to import it.

  2. 2

    Open the note

    Go to History and open it. Obinot transcribes and structures it, then shows the Summary and the Transcript.

  3. 3

    Ask, edit, organize

    Long-press the options button to chat about the note, or tap it for labels, editing, export and more.

Troubleshooting

“API key required”

Add your key in Settings. Recording and reading notes work without it; AI does not.

“Audio is too long for Groq” / file over 25 MB

Turn on Compression, or switch to Gemini or Dynamic, which handle long audio.

Rate limit / “try again in a moment”

Free tiers have limits. Wait a bit, add a second key from the other provider, or enable API Key Rotation in Advanced settings.

“No clear speech detected”

Record closer to the source, or in a quieter place, and try again.
